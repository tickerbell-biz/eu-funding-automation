# Contributing

Thank you for improving EU Funding Automation.

## Adding or correcting a source

Open an issue or pull request with the official website URL, country or region,
primary website language, and a short note explaining why it publishes funding
opportunities. Please use an official organisation domain rather than an
aggregator when possible.

## Data quality rules

- One registrable domain per row.
- Preserve the source and update-date basis; do not invent website update dates.
- Do not add personal data, credentials, or private application information.
- Verify that URLs use HTTPS when the site supports it.

## Development

The screening module uses Python's standard library. Run its validation and
review generated changes before opening a pull request.
