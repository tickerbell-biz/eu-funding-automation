# EU Funding Automation

An open-source workspace for finding, validating, and monitoring European
funding opportunities: grants, support funds, open calls, challenges, prizes,
and competitions.

## Modules

- [`eu-funding-screening/`](eu-funding-screening/) — a reproducible directory
  of 1,200 unique European funding-source domains, with an update program and
  validation report.

## Status

The first module is a discovery directory, not a claim that each organisation
currently offers an eligible open call. Always check the source website before
applying.
